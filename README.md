# LPC2148 Embedded Systems Experiments

## About This Repository
This repository contains my Embedded Systems practical experiments using the **LPC2148 microcontroller**. It includes Embedded C source code and Proteus circuit diagrams to demonstrate microcontroller interfacing and peripheral programming.

## Experiment 1: LED Interfacing with LPC2148

### Aim
To interface an LED with the LPC2148 microcontroller and control it using Embedded C programming.

### Software Used
- **Keil µVision:** Writing and compiling Embedded C code.
- **Proteus Design Suite:** Designing the circuit and simulating the experiment.

### Files Included
- `LED.c` – Embedded C source code for LED interfacing.
- `Circuit Diagram_LED.png` – Proteus circuit diagram of the experiment.

### Working Principle
The LPC2148 uses a General Purpose Input/Output (GPIO) pin to control the LED. The pin is configured as an output, and the program sets its logic level to control the LED according to the circuit connections.

### Result
The LED interfacing program and Proteus circuit diagram have been uploaded to this repository. The simulation result can be documented after verifying the circuit in Proteus.
